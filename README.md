## Now

**[BadStream](https://github.com/katrinalaszlo/badstream)** gives your AI app a bad day. Ten reproducible broken streams for OpenAI SSE and AI SDK UI: disconnects, silent cutoffs, stalls, 429s, half-finished tool calls. Zero runtime dependencies, no API keys. [Try the playground](https://katrinalaszlo.github.io/badstream/) or read [the finding that started it](https://github.com/katrinalaszlo/badstream/blob/main/docs/when-the-stream-ends.md): a truncated HTTP 200 throws nothing in the SDK clients I tested, and the UI shows a finished answer that isn't.
